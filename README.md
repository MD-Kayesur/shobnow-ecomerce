# SHOB Now - Premium E-Commerce Platform

A modern, high-performance, and feature-rich luxury e-commerce web application built with React 19, TypeScript, Tailwind CSS, and Redux Toolkit.

---

## 🌟 Key Features

- **Storefront & Navigation:**
  - Modern Header with Hotline, Delivery Promos, and Language/Currency switchers.
  - Multi-category Mega Menu with custom visual SVG icons.
  - Full-width interactive Brand Marquee.
  - Dual responsive promotional banners & seasonal discount sections.
  - Real-time product search, filters, and dynamic sorting.

- **Authentication & Authorization:**
  - Modern split-screen minimalist Sign In and Sign Up pages.
  - Role-based Access Control (Admin & Customer).
  - Quick 1-click Demo access for testing both roles.
  - Social authentication integrations (Google, Facebook, Twitter/X).

- **Shopping Experience:**
  - Dynamic Cart Drawer with real-time price calculation and free shipping trackers.
  - Instant Checkout flow with payment gateway integrations.
  - Wishlist and Order Tracking systems.

- **Dashboards:**
  - **Customer Dashboard:** Order history, profile management, addresses, and wishlist.
  - **Admin Management Panel:** Comprehensive sales analytics, product management, and order status controls.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, Radix UI, Lucide React, React Icons
- **State Management:** Redux Toolkit, React Redux
- **Routing:** React Router v7
- **Charts & Data Viz:** ApexCharts, React ApexCharts
- **Notifications:** Sonner Toast Notifications
- **Hosting & Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MD-Kayesur/shobnow-ecomerce.git
   cd shobnow-ecomerce
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
